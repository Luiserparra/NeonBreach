## Architecture (brief)

**Context:** Matches exist but start by opening the arena in PIE. Itch.io players need Host / Join IP (OnlineSubsystemNull, no Steam in MVP).

**Shape:** Maps `L_MainMenu`, `L_Lobby`, `L_Transition` (optional), `L_Arena`. Host creates a LAN listen session (`IOnlineSession` / `OnlineSubsystemNull`). Join: `ClientTravel` / session connect by IP (default UDP **7777**). Lobby UI: player list + Ready (replicated bool on `ANBPlayerState`) + Host Start when ≥2 ready (cut order allows “Start without Ready” if sessions slip). Travel: `ServerTravel` to arena; try seamless + transition map; **if PIE seamless fails**, non-seamless `ServerTravel` is the fallback (plan risks).

**Alternatives:**  
A) **(Recommended)** Null OSS + Join by IP; Find LAN is extra.  
B) Steam OSS now — auth/app id scope creep.  
C) Skip lobby, `open 127.0.0.1` only — weaker portfolio, valid fallback if days slip.

**Consequences:** + Demoable Host/Join. − NAT/internet not guaranteed; document LAN + port forward. Seamless in PIE is unreliable — validate in Standalone/packaged.

**Contracts:** Session name/settings documented. Ready bool replicated. GameMode lobby vs arena: use two GameModes (`ANBLobbyGameMode`, `ANBGameMode`) or one mode that branches on map — **prefer two GameModes** (SRP).

**NFRs:** Packaged or Standalone Host + Join on same PC. PIE may use `Play As Listen Server` + extra clients for a weaker test; do not call M7 done on PIE-only if Standalone travel fails.

**Implementation order:** maps + menu UI → Host session → Join IP → Ready/list → ServerTravel → smoke match.

## Networking notes

Host **is** the listen server (one player + authority). Join clients are `ROLE_AutonomousProxy`. Session APIs run on the machine that hosts; clients only connect. Ready is replicated; **Start is server-only**. After travel, existing PlayerStates should persist if using seamless + `bUseSeamlessTravel`; if non-seamless, PlayerStates rebuild — re-apply default pawn/abilities (already M3 init). Test disconnect-during-lobby later in M10.

Do not trust the client’s Ready to start the match: Host button on server checks Ready flags.
