## Architecture (brief)

**Context:** Fire proves predicted hitscan. The portfolio “star” is Dash prediction via root motion + CMC. Orb proves a replicated projectile. Barrier proves tags + damage modify in `PostGameplayEffectExecute`.

**Shape:** One C++ ability class per ability, BP/GE for numbers. Shared pattern: `UNBGameplayAbility` checks cost GE + cooldown tag, LocalPredicted policy. Orb: predict anim/sound; **spawn `ANBProjectile` only on server** (`SpawnActor` with `HasAuthority()`). Explosion: server overlap/sphere trace → `GE_Damage` + `GE_Slow`. Barrier: duration GE grants `State.Barrier`; AttributeSet reduces IncomingDamage by 60%. Cues (`GameplayCue`) for trails/explosion/looping shield so everyone sees them.

**Alternatives:**  
A) **(Recommended)** `UAbilityTask_ApplyRootMotionConstantForce` for Dash (predicts with CMC).  
B) LaunchCharacter / velocity impulse — rubber-bands under lag.  
C) Client-spawned orb with “server confirm” — projectile ownership fights; reject.

**Consequences:** + Three distinct net patterns in one week. − Cue and GE asset count grows; keep names 1:1 with tags. Rigid: projectile is server-only spawn.

**Contracts (plan numbers):** Dash 20 E / 4 s CD / 900 u / 0.2 s. Orb 35 E / 8 s / 1500 u/s / 35 dmg / 300 u radius / `GE_Slow` 2 s −40% speed. Barrier 40 E / 15 s CD / 3 s / 60% DR. Tags: `Ability.*`, `Cooldown.Ability.*`, `State.Barrier`, `State.Slowed`.

**NFRs:** 150 ms + 3% loss (`Net PktLag=150`, `PktLoss=3` or Emulation **Bad**). Dash: no visible CMC corrections (`p.NetShowCorrections 1`). Document in `docs/networking.md`.

**Implementation order:** cost/cooldown GEs + Energy spend on fire-unrelated abilities → Dash → Orb actor → Barrier + cues → lag test + doc.

## Networking notes

| Ability | Predict | Server authority |
|---|---|---|
| Dash | Root motion + cost/CD | Confirms GE; CMC replicates motion to others |
| Shock Orb | Anim/sound/cue on owner | Spawn projectile, overlap, damage, slow |
| Barrier | Local tag/cue | Duration GE; DR only in AttributeSet on server |

GameplayCues replicate by tag so non-owners see the shield/explosion without extra multicasts. Prefer cues over new reliable RPCs.

Lag acceptance (plan §5.5): firing and dashing feel instant; **no visible dash corrections** at 150 ms + 3% loss.
